Regra de negócio

Cinco passos, da medida ao valor.

Cada pedido passa pela mesma sequência. Os números abaixo acompanham o simulador lá em cima.

  1. Medidas

    5 × 3 cm

    Altura e largura do rótulo, na folha de 46,5 × 31,5 cm.

  2. Aproveitamento

    —

    Testa o rótulo deitado e em pé e fica com o encaixe que rende mais.

  3. Folhas

    —

    Quantidade de rótulos dividida pelo aproveitamento, arredondada para cima.

  4. Faixa de preço

    —

    Quanto mais folhas, menor o preço de cada uma.

  5. Valor

    —

    Preço da folha vezes o número de folhas, mais R$ 10,00 fixos.

O que o sistema faz

Do orçamento ao cadastro, tudo no mesmo lugar.

PedidoService

Orçamento calculado na hora

Escolha o papel, informe as medidas e a quantidade. O sistema calcula o aproveitamento da folha, o número de folhas e o valor, e recalcula tudo sempre que o pedido é alterado.

Interface

Menus simples, sem curva de aprendizado.

A interface usa caixas de diálogo nativas do Java (JOptionPane). Cada módulo tem as mesmas cinco opções: adicionar, listar, atualizar, deletar e voltar.

  • Seleção de cliente e de papel por lista, sem digitar nomes
  • Medidas aceitam vírgula ou ponto
  • Cancelar qualquer diálogo volta ao menu sem erro

Por baixo do capô

Cada camada tem um trabalho só.

O código segue a arquitetura em camadas. Clique em uma etapa para ver um trecho real do módulo de clientes.

ClienteView abre os diálogos e devolve o que o usuário digitou. Não decide nada: campos vazios seguem adiante para o service validar.

public Cliente informarDados() {
    String nome = JOptionPane.showInputDialog("Nome do Cliente:");
    if (nome == null)
        return null;
    String telefone = JOptionPane.showInputDialog("Telefone do Cliente:");
    if (telefone == null)
        return null;
    return new Cliente(nome, telefone);
}

ClienteController escolhe o que acontece depois de cada clique: pede os dados à view, entrega ao service e mostra o resultado.

private void cadastrar() {
    try {
        Cliente cliente = clienteView.informarDados();
        if (cliente == null) return;

        if (clienteService.cadastrar(cliente)) {
            clienteView.alertaSucesso("Cliente adicionado com sucesso!");
        } else {
            clienteView.alertaErro("Erro ao adicionar cliente.");
        }
    } catch (Exception e) {
        clienteView.alertaErro(e.getMessage());
    }
}

ClienteService guarda as regras de negócio. Aqui os erros são acumulados e devolvidos em uma única mensagem.

private void validarDados(Cliente cliente) throws ClienteException {
    String erros = "";
    if (vazio(cliente.getNome()))
        erros += "\n- Nome é um campo obrigatório";
    if (vazio(cliente.getTelefone()))
        erros += "\n- Telefone é um campo obrigatório";

    if (!erros.isEmpty()) {
        throw new ClienteException("Ops! Erros encontrados:" + erros);
    }
}

ClienteDao é a única classe que escreve SQL. Usa PreparedStatement e fecha a conexão sozinha.

public Boolean inserir(Cliente cliente) throws SQLException {
    String sql = "INSERT INTO tbcliente (nmcliente, nutelefone_cliente) VALUES (?, ?)";
    try (Connection conexao = ConexaoSQL.getConexao();
         PreparedStatement ps = conexao.prepareStatement(sql)) {
        ps.setString(1, cliente.getNome());
        ps.setString(2, cliente.getTelefone());
        return ps.executeUpdate() > 0;
    }
}

ConexaoSQL concentra o endereço do banco. Para usar outro computador, é o único arquivo que muda.

private static final String URL =
    "jdbc:postgresql://localhost:5432/projeto_final";
private static final String USERNAME = "postgres";

public static Connection getConexao() throws SQLException {
    return DriverManager.getConnection(URL, USERNAME, PASSWORD);
}

Para rodar

Três passos para abrir o sistema.

Você precisa do JDK instalado e de um PostgreSQL rodando na sua máquina.

  1. Crie o banco

    Crie o banco projeto_final e execute o script SQL das três tabelas, que está no README do repositório.

    createdb -U postgres projeto_final

  2. Ajuste a conexão

    Abra src/connections/ConexaoSQL.java e confira o endereço, o usuário e a senha do seu PostgreSQL.

    jdbc:postgresql://localhost:5432/projeto_final

  3. Compile e execute

    Na pasta Projeto Final Java. No Windows, troque : por ; no classpath.

    javac -encoding UTF-8 -cp libs/postgresql-42.7.13.jar -d out $(find src -name '*.java')
java -cp out:libs/postgresql-42.7.13.jar Principal

Dúvidas

Perguntas frequentes

Preciso instalar o PostgreSQL?

Sim. O sistema grava tudo no banco projeto_final, então ele precisa estar rodando antes de você abrir o programa.

De onde vem a folha de 46,5 × 31,5 cm?

É a área útil de impressão usada pelo cálculo de aproveitamento. Ela está fixa no PedidoService.

O que acontece se o rótulo for maior que a folha?

O sistema recusa o pedido e avisa que o rótulo não cabe. No simulador desta página você vê a mesma mensagem.

Os dados somem quando fecho o programa?

Não. Os dados ficam no PostgreSQL e continuam lá na próxima vez que você abrir o sistema.

O que acontece com os pedidos se eu excluir um cliente?

Os pedidos daquele cliente são excluídos junto, na mesma transação. Se algo falhar no meio, nada é apagado.

Funciona no Windows?

Sim. Basta ter o JDK instalado. Só os comandos de compilação mudam: o separador do classpath passa a ser ;.
